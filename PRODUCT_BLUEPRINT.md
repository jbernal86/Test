# Product Blueprint — Agent AI Plug Realtor OS

## Product position

**Agent AI Plug Realtor OS** is a practical AI agent command center for working real estate agents.

It is not positioned as a magic chatbot. It is a set of specialized business agents that help Realtors:

- prioritize leads
- draft follow-ups
- clean up CRM chaos
- prepare listings
- create content
- follow up after open houses
- review compliance risk
- manage their daily execution

## Core promise

> Turn scattered real estate work into a daily action queue with AI-drafted outputs and human approval before anything goes out.

## Best first customer

The first customer is a solo or small-team residential agent who:

- has leads sitting in a CRM
- struggles with consistent follow-up
- wants AI help but does not know how to structure it
- does not want to become technical
- needs practical outputs, not theory

## V1 agents

The first sellable kit should include eight agents:

1. Lead Triage Agent
2. Follow-Up Drafting Agent
3. CRM Cleanup Agent
4. Listing Prep Agent
5. Content Repurposing Agent
6. Open House Follow-Up Agent
7. Compliance Review Agent
8. Daily Operator Agent

## Dashboard sections

The UI should be simple and feel like an operator cockpit:

1. **Today** — money-first daily command plan
2. **Leads** — ranked leads and recommended actions
3. **Drafts** — text/email/call scripts awaiting approval
4. **CRM Cleanup** — stale leads, missing tags, bad statuses, duplicates
5. **Content Engine** — post ideas, captions, video scripts
6. **Listings** — listing launch checklists and seller prep
7. **Compliance** — risk flags and safer rewrites
8. **Settings** — agent tone, market, brokerage info, approval rules

## Non-negotiable safety rules

- The system drafts; the agent approves.
- No automatic sending in V1.
- No private client data in demo mode.
- No MLS scraping.
- No Fair Housing steering language.
- No claims like "best agent" unless substantiated and compliant.
- No API keys committed to GitHub.

Most AI products for agents are vague. This should be concrete:

- exact agents
- exact workflows
- exact UI
- exact approval queue
- exact demo outputs
- safe test mode

Agents need to see the result in 5 minutes.
