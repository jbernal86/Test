# Demo Script — Agent AI Plug Realtor OS

Use this when showing the product to another Realtor.

## 30-second opening

Most agents do not need another chatbot. They need a command center that tells them what to do next, drafts the work, and keeps them in control before anything gets sent.

Agent AI Plug Realtor OS gives you a set of focused AI agents for lead follow-up, CRM cleanup, listing prep, content, open house follow-up, compliance review, and daily execution.

## Demo flow

### 1. Show the dashboard

Open:

```text
output/dashboard.html
```

Say:

> This is the Realtor command center. The goal is not to replace the agent. The goal is to turn scattered work into an approval queue.

### 2. Point out Today’s Command Queue

Say:

> The system starts with money-first tasks. Who should you contact? What should you say? What needs review before action?

### 3. Show the agent library

Say:

> Each agent has one job. Lead triage ranks people. Follow-up drafting writes messages. CRM cleanup finds missed opportunities. Compliance review flags risky language.

### 4. Show the approval model

Say:

> Nothing sends automatically. The agent reviews, edits, approves, skips, or escalates.

### 5. Show generated outputs

Open:

```text
output/daily_report.md
output/approval_queue.json
```

Say:

> The dashboard is the visual layer. These files are the structured outputs that could later plug into Notion, Gmail drafts, n8n, Zapier, Make, or a CRM workflow.

## Best closing line

> This is not AI hype. This is a practical operating system for agents who need help staying consistent with follow-up, content, listing prep, and CRM cleanup.

## Questions to ask the Realtor

- What CRM are you using?
- How often are you following up with old leads?
- Do you have leads that never got tagged or cleaned up?
- Would a daily approval queue make your follow-up easier?
- Do you want AI to draft, or are you comfortable with it taking action after approval?
